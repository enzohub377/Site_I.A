📘 Plano Bem Bolado – Landing Page

Este projeto é uma Landing Page promocional desenvolvida em HTML e CSS, focada na divulgação de um evento/aula sobre criação de aplicativos com ChatGPT e Inteligência Artificial.

A página foi pensada para conversão, destacando benefícios, cronograma das aulas e autoridade do professor.

🎯 Objetivo do Projeto

O objetivo do Plano Bem Bolado é:

Apresentar uma proposta educacional clara e atrativa

Captar leads através de um formulário de lista de espera

Comunicar valor usando estrutura visual simples e direta

Simular uma página real de lançamento de curso/evento online

🖥️ Tecnologias Utilizadas

HTML5 — Estrutura semântica da página

CSS3 — Estilização, layout e responsividade

Imagens (.png) — Ícones e imagem do professor

O projeto não utiliza JavaScript, mantendo o foco em estrutura e design.
