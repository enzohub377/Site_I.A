# Laboratório Aberto | Tecnologia Criativa

Um encontro prático focado em explorar ideias, inteligência artificial e tecnologia criativa. Este repositório contém o código-fonte do site oficial do evento.

## 🚀 Sobre o Projeto

O **Laboratório Aberto** é um espaço imersivo criado para tirar projetos do papel, experimentar ferramentas de inteligência artificial e descobrir novas formas de resolver problemas reais através da tecnologia.

O site foi desenvolvido com foco em performance, acessibilidade e design limpo, destacando a programação do evento, a dinâmica das atividades e o facilitador.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web modernas e nativas:

* **HTML5 Semântico:** Estrutura acessível com tags apropriadas e navegação amigável (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).

* **CSS3 Avançado:**

  * Variáveis CSS (`:root`) para gerenciamento consistente de paleta de cores e tipografia.

  * Layouts responsivos usando **CSS Grid** e **Flexbox**.

  * Unidades relativas (`clamp()`) para tipografia fluida e adaptável.

  * Estilização visual detalhada com gradientes radiais, sombras e elementos textuais customizados.

* **Google Fonts:** Utilização das famílias tipográficas **Space Grotesk** (títulos/display) e **DM Sans** (corpo de texto).

## 🌟 Principais Seções do Site

1. **Cabeçalho (Header):** Identidade visual minimalista (`L / laboratório aberto`) e navegação principal com links de ancoragem e botão de chamada para ação (CTA).

2. **Início / Hero Section:** Apresentação principal com título de destaque, descrição do propósito, link direto para a programação e fatos rápidos sobre o encontro. Acompanha o retrato em destaque do facilitador.

3. **Programação (Do primeiro rascunho ao próximo passo):** Lista detalhada dividida em três etapas práticas:

   * *01. Encontre a ideia* (Explorar)

   * *02. Prototipe com IA* (Experimentar)

   * *03. Teste e refine* (Compartilhar)

4. **Facilitador:** Seção dedicada a **Brenno Sullivan** (Especialista em inteligência artificial e tecnologia, head de tecnologia da VAROS e formado em Economia pela UFF).

5. **Rodapé (Footer):** Fechamento institucional com identidade visual e atalho de retorno ao topo.

## 📱 Responsividade

O site conta com estilizações adaptativas via **Media Queries** no arquivo `style.css`, garantindo uma experiência fluida e organizada em dispositivos móveis, tablets e telas de desktop.
